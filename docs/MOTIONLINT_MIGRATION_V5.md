# 迁移到 MotionLint 0.5.0

| 项目 | 0.5.0 约定 |
| --- | --- |
| 默认规则 | v5；v4、v3 可选 |
| 修复算法 | v6，与规则独立记录 |
| 报告 | 格式 v3，保留已有字段，增加上下文、接触、求解与证据类型 |
| 回归比较 | 内部、CLI、Web、批量使用同一模块 |
| 独立报告比较 | 缺少原数组或时间对应返回不完整，退出 1 |
| BVH 修复 | 映射充分时支持腿部脚滑修复；写出回读 FK 复检 |
| 修复状态 | no_op / accepted / rejected / unsupported / failed，附原因码 |
| 新入口 | doctor / resources / serve / pipeline / benchmark |
| 工作台 | wheel 包含编译资产，用户无需 Node |
| 数据目录 | 独立于仓库和 site-packages，可指定 |

数值阈值保持原设定，改进根加速度、有方向旋转导数、地面冻结、显式接触例外及骨架层级检查。新旧规则分数不得直接相减。
优化扩展锁定 CVXPY 1.6.5、Clarabel 0.11.1；未安装仍运行已有候选并记录能力缺失。历史报告可查看，缺少 v3 上下文时不能当作当前严格回归通过；新产物 UUID 目录保留旧记录。
