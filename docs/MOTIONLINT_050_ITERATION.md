- 初始 dynamic-1 注入布局未评估；dynamic-2 采用解析支撑和落地区间，600 条独立真值核验完成。按原轨迹分组，240 开发、360 保留，不跨组。
- 24 InterGen 开发；12 InterGen 和24 Bandai 保留，12 类提示词每类三个固定种子、6 类外部内容四种风格；没有人工语义打分。
- 保留测试前冻结检测/修复代码、规则、输入及哈希，后续只改交付、角色转换和实验运行器，不调保留集规则。
- 初次大报告汇总及长对照进程出现 MemoryError。失败日志保留；改为紧凑索引与小批串行进程，按原输入续跑，无失败质量样本删除。
- InterGen 初次加载错误与重试记录保留，36 条最终生成均有实际模型检查点、请求、种子及文件哈希。
- 角色流程 v1 暴露 Bandai 绑定姿态与自动缩放不匹配；v2 改用真实 BVH 全局位置的已记录转换代理；v3 修正跨关节顺序的几何误差测量。各版本保留。
- 交付复测修正任务按随机 UUID 排序和浏览器误读旧任务完成状态的问题；按创建时间展示，按本次任务编号验证。前端升级锁定 Axios 1.20.0、Vue 3.5.43 并修复可兼容更新的传递依赖，完整 npm 审计为 0 条。检测与修复冻结不受这些交付修改影响。
- 录制接口兼容失败保留日志，最终使用带时间戳的实际浏览器截图序列生成操作视频；保留 923 个实际屏幕帧，合成讲解明确为自动语音，不生成用户经历。
- 接触文件的单独 SHA 在交付时补录，记录其真实时间边界；注入数组和参考数组仍与测试前清单的哈希一致。
- 最终归档审查发现绝对路径字典键未被脱敏，且路径正则误伤来源 URL；改为同时处理键和值、为不同输入保留独立标签并保持公开来源链接。旧候选归档作为失败尝试保留，以最新交付清单为准。
