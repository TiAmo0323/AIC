# MotionLint 校准与修复复测记录

**后续几何核查：** 下方分数是原固定 BVH 骨架下的历史测量。LODGE 检测现已改用本机渲染的 SMPL-X neutral 骨架，重新测得 aic260929 总分 `89.48→89.96`、063 总分 `87.19→88.57`，严格门仍为 FAIL。两套测量不可混用；详见[质量门诊断](MOTIONLINT_GATE_DIAGNOSIS_20260930.md)。

本轮使用 `experiments/baseline_motions.json` 中的本机任务产物。两条 LODGE 任务使用合成节拍验证生成链路，不代表真实音乐数据集；`intergen_handshake_b` 与 `intergen_handshake_a` 分数和动作相同，未作为独立样本计数。原始与连续化后的 LODGE 文件也属于同一次生成，只以连续化后文件作为 Foot Lock 的输入。

## 检测校准

LODGE 四个接触通道在 `aic260929` 的 1024 帧中，有 974 帧同时为真；`063` 中有 722 帧同时为真。因此“仅一个接触通道有效才修复”的原策略会跳过绝大多数动作。新检测把接触通道与每个脚关节相对于自身低位高度的条件合并，避免把踝关节和脚尖的不同静止高度混为同一地面。合成单脚滑动、双脚共同滑动及原有地面穿透测试均通过。

对八个已有文件重新批量检测，`8/8` 成功读取，`0/8` 通过当前严格质量门。批量原始结果在本机 `reports/baseline_after_calibration/`，该目录含绝对路径，不提交到仓库。

完整流水线对合成的静止正常动作给出 Quality Gate `PASS`；在同一动作上注入每帧 0.008 米的水平根位移后，质量门变为 `FAIL`，回归比较将脚滑项标记为 `REGRESSION`。这验证了门限和回归的基本方向，但不能替代人工标注的真实动作集。

## 限制和下一轮验证

LODGE 仅修改根节点水平平移并保留原接触和旋转通道，故无法消除两脚相反方向的滑动。InterGen 直接修正关节轨迹，需继续以骨长和主观画面检查约束。当前阈值基于少量合成节拍与生成样例，尚没有人工标注的真实舞蹈基准，也没有足以报告统计显著性的样本量。报告和视频中应同时展示修复被拒绝的案例。
