## 作品名称与方向

- 作品名称：MotionLint 人体动作质检平台
- 推荐申报方向：AI 开发工具与开源协作；同时说明对生成式人体动作项目的可验证改进。
- 作品形态：Windows 本地 Web 工具、CLI、测试脚本和技术文档。

## 作品简介（待审核，控制在 300 字内）

生成式人体动作常出现脚底滑动、接缝跳变、骨架异常和碰撞，仅靠观看视频难以稳定定位与回归比较。MotionLint 接入 InterGen 双人动作和 LODGE 音乐舞蹈输出，统一动作表示，提供六项自动检查、问题帧定位、质量门、有限修复和修复前后复测，并生成可播放的对比视频与 CSV/JSON 报告。本地实验中，三条样例接受脚滑修复，两条候选因复测未改善而被拒绝；当前真实样例仍未通过严格质量门。项目开放可复用的质检代码、测试与文档，模型权重和受限人体模型由使用者自行获取。

## 技术报告正文结构

1. **问题与目标**：生成动作的脚滑、接缝、碰撞难以系统验收；目标是提供可重复的自动检查和有限修复。
2. **方案架构**：InterGen/LODGE 输出 → 适配器 → `MotionSequence` → 六项测试 → 质量门 → 修复 → 复测 → 对比视频与报告。说明第三方模型与自主代码的边界。
3. **核心实现**：关节坐标/接触通道归一化、脚滑判据、根节点与关节修复、回归拒绝条件、InterGen 多候选物理质量排序、任务目录持久化、Web/CLI 接口。
4. **验证方法**：合成注入异常单测、五条非重复任务的前后对比、八个已有文件的批量质检；列出输入、FPS、阈值、硬件和运行命令。
5. **结果**：引用 `MOTIONLINT_EXPERIMENT_20260930.md` 的表格；如实写 `0/8` 基线通过质量门、三条修复接受、两条拒绝，以及抖动指标小幅下降。
6. **创新与开放成果**：跨生成器统一质检、可定位问题帧、修复后全量复测、自动拒绝有害修复、可复用测试和文档。不要把 InterGen/LODGE 本身称为团队原创。
7. **授权和限制**：引用 `THIRD_PARTY_NOTICES.md`、`MODEL_LICENSES.md`、`ASSET_LICENSES.md`；披露辅助编程工具的使用及人工审核、测试；说明 LODGE 许可待核、SMPL-X 不再分发、目前样本规模有限。
8. **复现说明与展望**：源码仓库、`LOCAL_SETUP.md`、`docs/MOTIONLINT_USAGE.md`、测试命令和后续接触检测/IK 改进方向。

**AI 辅助工具披露草稿**：开发期间使用 Codex 辅助阅读现有代码、实现 MotionLint 模块与 Web 展示、运行测试、整理实验记录和起草文档。自动化测试、真实任务复测及视频抽帧检查已记录；团队成员仍须亲自审核生成代码、报告文字、授权边界和演示内容，提交材料不能把 AI 输出直接声明为团队独立创作。
